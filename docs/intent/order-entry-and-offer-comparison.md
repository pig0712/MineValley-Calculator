# 주문 수량 생략과 납품 제안 비교

## 목표

게임 채팅에서 받은 제안을 그대로 입력하고, 보유한 재고로 어느 제안을 받을 때 개당 가격과 이득이 높은지 한눈에 판단한다.

## 작업 범위 및 완료 기준

- 한 줄 주문에서 수량을 생략하면 1개로 해석한다. 예를 들어 `광물창고 4 5000만`은 광물 창고 IV 1개, 총 50,000,000 C다. 수량을 지정한 입력과 개당·총액 표기도 계속 사용할 수 있다.
- 납품 제안을 비교할 때 각 제안을 동일한 시작 재고로 따로 계산하고 수량, 개당 제안가, 총 납품액, 비용과 사용 재고 가치를 차감한 이득을 함께 표시한다. 어떤 주문을 먼저 입력했는지에 따라 제안 비교 결과가 바뀌지 않아야 한다.
- 여러 주문을 모두 납품하는 계산에서는 공유 재고를 한 번씩만 배정한다. 사용자가 현재 보고 있는 계산의 기준을 화면에서 알 수 있어야 한다.
- 검증 사례로 모터 재고 50개에 모터 50개를 300만 C와 235만 C에 각각 요청한 두 제안을 사용한다. 같은 재고로 한 건을 고를 때 개당 제안가는 각각 60,000 C와 47,000 C이며, 높은 제안의 이득이 650,000 C 더 크다.

## 범위에서 제외

주문 초안 자동 보존, 전량 보유 버튼, 가공대 투입량 즉시 갱신, 게임 레시피 및 가격 데이터 갱신.
