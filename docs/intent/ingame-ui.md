# 마인밸리 공방 인게임 UI 개편

## 목표

마인밸리에서 인벤토리와 메뉴를 열고 조작하는 느낌을 계산기 전체에 적용한다. 품목을 그림으로 빠르게 찾고 제작 중 준비 상태를 바로 알아볼 수 있도록 한다.

## 작업 범위

- 품목 선택창을 아이템 그림과 이름이 있는 슬롯 격자로 만든다. 분류 탭과 검색으로 범위를 좁히고, 슬롯을 고르면 수량 입력으로 이어지게 한다.
- 화면 하단 단축바에서 제작·납품·가공대·재고·설정을 창으로 연다. 열려 있는 창은 닫기 버튼과 Esc로 닫을 수 있게 한다.
- 계산 결과, 표, 대화상자를 각진 패널과 픽셀 테두리로 통일한다. 제작 수량, 재고, 부족량을 스캔하기 쉽게 유지한다.
- 버튼과 준비 체크박스에 오리지널 픽셀 스타일을 적용한다. 기본·가리킴·누름·선택·키보드 초점 상태를 구분한다. 체크박스는 표시와 색으로 상태를 전달하며, 일부 준비 상태도 구분한다.
- 마우스, 키보드, 모바일 터치에서 슬롯 선택과 메뉴 열기·닫기, 체크 상태 변경을 확인한다.

## 완료 기준

사용자가 품목 선택창에서 슬롯을 빠르게 찾고, 단축바로 메뉴를 열고 닫으며, 체크박스를 눌렀을 때 상태 변화를 즉시 확인할 수 있다. 좁은 화면에서도 필요한 수량과 조작 버튼에 접근할 수 있다.

## 범위에서 제외

레시피·가격·재고 차감 등 계산 규칙과 저장 데이터 형식 변경, 게임 UI나 새 게임 에셋의 동일 복제.
