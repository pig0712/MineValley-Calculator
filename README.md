# 마인밸리 공방

마인밸리에서 주문을 받았을 때 **무엇을 얼마나 만들어야 하는지, 어느 주문이 더 이득인지** 계산해 주는 웹앱입니다.

- **제작 계산** — 보유한 완제품과 재료를 반영해 부족한 수량, 제작 횟수, 예상 시간을 보여줍니다.
- **납품 비교** — 같은 재고로 여러 주문의 개당 가격과 이득을 비교하고, NPC에 바로 팔 때 받을 금액도 확인할 수 있습니다.
- **가공대** — 만들 품목과 목표 수량을 고르면 각 라인에 넣을 재료를 계산합니다.

프로젝트 폴더의 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다. 예를 들어 주문 입력란에 `스프링클러 3 15개 3000만`을 넣으면 스프링클러 III 15개를 총 3,000만 C에 납품하는 주문으로 계산합니다.
